# User stories (each maps to backlog issues)
- As a student I want to search by city, neighborhood, price and rooms so I see only relevant flats. (#10)
- As a renter I want weekly and monthly rents shown as one monthly total including utilities when known so I can compare honestly. (#5, #11)
- As a renter I want prices in my currency, with the rate and date shown, so I understand converted values. (#5, #11)
- As a renter I want to filter by type and amenities. (#10)
- As a renter I want to sort by lowest, highest and newest. (#10)
- As a renter I want details, the source, a link back to the original and when it was updated. (#11)
- As a renter I want to compare up to three listings side by side. (#12)
- As a renter I want to save favorites and see them later. (#13)
- As a renter I want to know when two listings are probably the same flat, without anything being deleted. (#7, #11)
- As a renter I want to refresh sources and see which worked. (#14, #26)
- As a user on a phone I want every page to work at 360px. (#16)
- As a user I want clear loading, empty and error states. (#15)
- As a demo viewer I want to be told that listings are sample data. (#9, #11)
