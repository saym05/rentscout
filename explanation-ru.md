# RentScout — коротко о проекте

## Что это и зачем
**RentScout** — веб-приложение для сравнения аренды жилья. Оно для иностранных студентов и тех, кто переезжает в новый город.

Проблема: на разных сайтах цены указаны по-разному — где-то за неделю, где-то за месяц, коммуналка то включена, то нет, валюты разные, а одна и та же квартира часто выложена дважды. Понять, сколько ты **реально** будешь платить в месяц, сложно.

RentScout приводит каждое объявление к **одной честной цифре в месяц** и позволяет их сравнивать.

## Что умеет приложение
- **Поиск и фильтры:** город, район, бюджет, количество комнат, тип жилья (студия, квартира, комната, дом), удобства (Wi-Fi, мебель, балкон…), сортировка (дешевле / дороже / новые), постраничный вывод.
- **Реальная месячная стоимость:** недельная аренда × 52 ÷ 12, плюс коммуналка, если она не включена и известна. Если коммуналка неизвестна, мы это помечаем и ничего не выдумываем.
- **Валюты:** EUR, GBP, CAD, USD. Исходная цена всегда показывается. Пересчитанная цена помечена знаком «≈», а курс, дата и источник курса указаны рядом.
- **Поиск дублей:** если два объявления похожи на одну квартиру, приложение показывает процент сходства и **причины** (тот же район, те же комнаты, цена в пределах 2% и т.д.). Ничего не удаляет и не объединяет.
- **Сравнение** 2–3 объявлений бок о бок, самое дешёвое подсвечивается.
- **Избранное:** сохранить понравившееся (♥) и вернуться позже.
- **Своё объявление:** можно добавить объявление, найденное в другом месте, и отредактировать или удалить его.
- **Источники данных:** страница со статусом каждого источника и кнопкой «Обновить». Если один источник упал, остальные данные сохраняются.
- **Адаптивный дизайн:** работает на телефоне и на компьютере, с учётом доступности (контраст, клавиатура, подписи полей).

> Важно: все объявления — **демо-данные** (помечены значком DEMO), курсы валют фиксированные и подписаны «not live». Реальные сайты аренды не подключены: бесплатного легального API для этого нет.

## Технологии
| Часть | Стек |
|---|---|
| Фронтенд | React 18 + TypeScript + Vite, React Router |
| Бэкенд | Python, FastAPI |
| База данных | SQLite через SQLAlchemy 2 (без SQLite-специфичного SQL, можно сменить БД через `DATABASE_URL`), миграции Alembic |
| Контракт API | `openapi.yml` (OpenAPI 3, 12 операций) |
| Тесты | pytest (бэкенд), node:test + Vitest + Testing Library (фронтенд), Playwright (E2E в браузере) |
| Запуск | `run.sh`, uv (Python), npm |

## Как устроено
```
React UI ──► ApiService (интерфейс)
                ├─ MockService — данные прямо в браузере (для тестов и офлайн)
                └─ HttpService ──► FastAPI ──► сервисы ──► репозитории
                                                           ├─ в памяти
                                                           └─ SQLite (SQLAlchemy)
Адаптеры источников (демо) ──► обновление (refresh) ──► репозитории
```
- Бизнес-логика (расчёт цены, поиск, дубли) — чистые функции без ввода-вывода. Она написана на TypeScript и повторена на Python.
- Общие **тестовые векторы** (`docs/test-vectors.json`) гарантируют, что фронтенд и бэкенд считают одинаково, до цента.
- UI зависит только от интерфейса `ApiService`, поэтому мок и настоящий бэкенд легко меняются местами.

## Как запустить
```bash
./run.sh            # бэкенд http://localhost:8091 + сайт http://localhost:5173
./run.sh --reset    # с чистой базой
./run.sh --mock     # только фронтенд, без бэкенда
```
Документация API: http://localhost:8091/docs

## Что мы сделали (кратко)
1. **Сначала логика:** расчёт месячной цены, поиск, фильтры и поиск дублей на TypeScript, с тестами.
2. **Мок-сервис** и детерминированные демо-данные: 3 города, 3 валюты, 27 объявлений, по одному специальному дублю на город.
3. **Контракт API** в `openapi.yml`, проверенный внешним валидатором. Валидатор нашёл ошибку в YAML, мы её исправили.
4. **Бэкенд на FastAPI:** сначала хранение в памяти, потом SQLite с миграциями. Данные переживают перезапуск сервера.
5. **Обновление источников:** блокировка от двойного запуска (ответ 409), сбой одного источника не удаляет данные.
6. **React-интерфейс:** главная, поиск, карточка объявления, сравнение, избранное, источники, добавление объявления.
7. **Тесты:**
   - бэкенд — 126 тестов (каждый на двух хранилищах);
   - фронтенд — 44 + 26 тестов;
   - E2E — полный сценарий в браузере, с перезапуском сервера и проверкой сохранности данных.
8. **Найденные и исправленные баги:**
   - падение подсчёта на SQLite;
   - несоответствие контракта (поля курса могли быть `null`);
   - текст ошибки внутри `<label>`, что мешало скринридерам;
   - ошибка в YAML.
9. **Дизайн:**
   - тёплая «бумажная» палитра, тёмно-синий и бирюзовый, шрифты Fraunces и Source Sans 3;
   - новая главная страница с примером расчёта, карточками городов, блоком про дубли и призывом к действию.
10. **`run.sh`** для запуска всего одной командой и обновлённая документация.

## Что осталось / ограничения
- Нет реальных источников объявлений, только демо.
- Курсы валют фиксированные, не живые.
- «Пользователь» для избранного — демо-заголовок `X-Demo-User`, это не настоящая авторизация.
- Ручное тестирование в браузере не проводилось. Последняя правка E2E-теста не перезапускалась.
- GitHub-репозиторий и задачи не создавались, так было решено. Бэклог лежит в `docs/backlog.md`.

## Где что лежит
- `frontend/` — сайт (`src/domain` — логика, `src/pages` — страницы, `src/services` — API-клиенты)
- `backend/` — сервер (`app/domain`, `app/services`, `app/repositories`, `migrations/`)
- `openapi.yml` — контракт API
- `docs/` — спецификация, архитектура, дизайн, решения, тестирование, ограничения
- `run.sh` — запуск
